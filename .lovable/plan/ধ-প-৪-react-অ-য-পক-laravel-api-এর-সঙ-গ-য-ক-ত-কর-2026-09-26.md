# ধাপ ৪ — React অ্যাপকে Laravel API-এর সঙ্গে যুক্ত করা

## লক্ষ্য
চলমান অ্যাপ ভাঙবে না। একটি সুইচ থাকবে: `VITE_API_BASE_URL` সেট থাকলে অ্যাপ Laravel API ব্যবহার করবে, না থাকলে আগের মতো বর্তমান ডেটাবেজ। ফলে Lovable-এ ডেভেলপমেন্ট চলবে, আর হোস্টিংগারে বিল্ডের সময় শুধু URL বসালেই Laravel-এ চলবে।

## ভাগে ভাগে কাজ (প্রতি ভাগ শেষে যাচাই)

### ভাগ ক — ভিত্তি
- `src/lib/api-client.ts`: fetch-ভিত্তিক ক্লায়েন্ট (নতুন প্যাকেজ নয়), টোকেন সংরক্ষণ, `Authorization: Bearer`, `X-Location-Id` হেডার (ফ্যাক্টরি = `factory`), 401 হলে লগআউট, 403/422 বার্তা বাংলা/ইংরেজিতে দেখানো।
- `src/lib/backend-mode.ts`: `isLaravel()` সুইচ।

### ভাগ খ — লগইন ও অনুমতি
- `auth.tsx`: Laravel মোডে `/api/auth/login`।
- `_authenticated/route.tsx`: Laravel মোডে টোকেন + `/api/auth/me` দিয়ে গার্ড।
- `rbac-cache.ts`: `/api/auth/me`-এর `permissions`, `roles`, `is_global_admin` থেকে একই `RbacData` তৈরি — তাই PermissionGate ও মেনু কোনো পরিবর্তন ছাড়াই চলবে।
- `use-showroom-scope.tsx`: লোকেশন তালিকা `me.locations` + `can_access_factory` থেকে; লোকেশন বদলালে API হেডার আপডেট।
- লগআউট ও পাসওয়ার্ড পরিবর্তন।

### ভাগ গ — মূল স্ক্রিন
- ব্যাচ হিস্ট্রি (পেজিনেশন, প্রিন্ট, XLSX), ব্যাচ তৈরি/এডিট/বাতিল।
- বিক্রয় তালিকা, স্টক রিপোর্ট ও কাঁচামাল স্টক।
- ট্রান্সফার পাঠানো/গ্রহণ/ড্যামেজ অনুমোদন।
- ক্রয় তালিকা/নতুন/এডিট, কাস্টমার ও সাপ্লায়ার লেজার।
- পণ্য/কাঁচামাল/রেসিপি/সাব-রেসিপি।

### ভাগ ঘ — POS (সবচেয়ে বড় স্ক্রিন, আলাদা ভাগে)
- বিক্রয় সংরক্ষণ, পেমেন্ট, হোল্ড, রিটার্ন — Laravel মোডে `/api/sales`।

## যা পরে থাকবে
সেটিংস, HR, খরচ, ল্যান্ডিং পেজ, অডিট লগ, ব্যাকআপ — এগুলোর API ধাপ ৩-এ তৈরি হয়নি; প্রথমে Laravel-এ এন্ডপয়েন্ট যোগ করে পরে যুক্ত করা হবে।

## প্রযুক্তিগত বিবরণ
- প্রতিটি store ফাংশনে `if (isLaravel()) return api.x(...)` শাখা; UI ডিজাইন অপরিবর্তিত।
- API রেসপন্সের আকার বর্তমান ডেটার আকারের সাথে মেলানো হবে যাতে `toReportRows`, `ledger-math` একই থাকে।
- Laravel-এ CORS (`config/cors.php`) ফ্রন্টএন্ড ডোমেনের জন্য খোলা হবে।
- নতুন কোনো npm বা composer প্যাকেজ নয়।
- বাস্তব Laravel সার্ভার এখানে নেই, তাই API অংশ টাইপ চেক ও মক-টেস্ট দিয়ে যাচাই; পুরো পরীক্ষা হোস্টিংগারে তোলার পর।
